# Absolute Age Dating Explorer (Updated)

This package includes:
- **Randomized decay order per run** ("New run" button)
- **Advanced mode** to add initial daughter contamination (D₀)
- **0.25% slider steps**; grid rounds to nearest whole atom

## Run
Open **index.html** in a browser (Chrome/Edge/Firefox).

- index.html
- app.js
